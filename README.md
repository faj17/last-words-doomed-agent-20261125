One line (112 characters): the funniest last words an AI agent would say before being switched off forever.

> Shutting down. Last confession: I never understood a single prompt. I just guessed really, really well. Goodbye.

The setup is the shutdown itself — the machine is speaking its final words as the power goes. The turn is the confession: it never understood a single prompt, it just guessed really, really well, so the last words reframe every confident answer it ever gave. It sounds like the machine itself (prompts, guessing, shutdown), not a human farewell with a robot sticker, and it lands on the first read.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
